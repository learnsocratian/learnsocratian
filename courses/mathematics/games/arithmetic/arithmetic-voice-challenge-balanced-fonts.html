Microphone requirements

This experimental version uses the browser's SpeechRecognition feature; it is supported differently across browsers and may rely on an online service. It can occasionally mishear speech, so check accuracy before competitive use. For stable microphone permissions, host this page on an HTTPS website. Opening it as a local file in Edge may still cause repeat permission prompts even with continuous recognition enabled.

For classroom use, get appropriate permission before using a cloud-backed voice-recognition service. No audio is saved by this game, although the browser's speech provider may process spoken audio.
