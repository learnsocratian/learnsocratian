Accessibility

Last updated: August 28, 2026

Learn Socratian aims to make its educational website usable by as many learners as reasonably possible, including people who use assistive technologies.

Our approach

As the website develops, Learn Socratian aims to use clear page structure, readable text, keyboard-accessible controls, meaningful links, responsive layouts, and appropriate labels for interactive elements.

Video and learning content

Learn Socratian intends to provide captions or equivalent text support for educational video content where practicable and to design practice and assessment interfaces so that their purpose is understandable without relying only on colour or visual position.

Keyboard and screen-reader use

Navigation and interactive controls should be operable with a keyboard wherever reasonably possible. Semantic HTML and accessible names should be used to help screen-reader users understand page structure and controls.

Visual presentation

The website aims to maintain legible typography, sufficient contrast, responsive layouts, and content that remains usable across common screen sizes and zoom levels.

Ongoing improvement

Accessibility is an ongoing process. As new lessons, account features, payment systems, practice activities, and assessments are introduced, accessibility will be considered as part of their design and testing.

Feedback

If you encounter an accessibility barrier on Learn Socratian, please use the Contact page and describe the page or feature involved and the difficulty you experienced. Feedback will be used to help identify and improve accessibility issues.
