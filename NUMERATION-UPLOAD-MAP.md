# Numeration page upload map

Upload the files from the bundle into the matching locations in the root of the LearnSocratian repository.

| File | Repository location | Purpose |
| --- | --- | --- |
| `courses/mathematics/topics/numeration/index.html` | Same path | Numeration topic page |
| `courses/mathematics/index.html` | Same path | Adds the Numeration card to Learn by Topic |
| `assets/css/numeration.css` | Same path | Fullscreen film and topic-page styling |
| `assets/js/numeration-film.js` | Same path | Click-to-play and replay behaviour |
| `assets/video/learn-socratian-numeration-film.mp4` | Same path | Corrected Numeration film with exact captions |
| `assets/images/numeration/numeration-film-poster.jpg` | Same path | Paused fullscreen poster |

Do not upload the enclosing bundle folder itself. Preserve the paths above.

`courses/mathematics/topics/numeration/`
